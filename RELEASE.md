# PDF MV release status

No PDF MV release, hosted service, or container image has been published. The inherited package version identifies the upstream base, not a stable PDF MV release.

Before the first release, define versioning, validate production artifacts and supported tool flows, review deployment and dependency licensing, and publish source corresponding to the distributed build. Publishing workflows are not enabled by this documentation.

Historical BentoPDF release instructions are retained in [docs/upstream/RELEASE.md](docs/upstream/RELEASE.md).
