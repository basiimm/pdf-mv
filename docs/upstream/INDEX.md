# Archived BentoPDF reference

These files preserve historical upstream documentation and automation from the BentoPDF base. They are not active PDF MV contribution policies, commercial offers, deployment instructions, or workflows. Refer to the [PDF MV README](../../README.md) for current guidance.

Files under `workflows/` have a `.disabled` suffix and are outside `.github/workflows/`; GitHub does not execute them. They include the upstream commercial CLA, sponsorship, publishing, and engine update automation.

Original legal notices and license terms remain applicable to their respective code and dependencies. The archived CLA documents are upstream reference only; PDF MV does not ask contributors to sign them.
